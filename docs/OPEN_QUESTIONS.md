| OQ-38 | **New in Phase 4E.** ScienceWorld's valid-action *referent text* depends on which free queries were made earlier in the episode. The same recipe, with `capture_state` / `valid_action_templates` calls interleaved between steps, yields a different valid-action list. For example, "soil in flower pot 1 containing soil" appears in one list where "soil in flower pot containing soil" appears in the other. The canonical object state is unchanged (`21` §3.2). Which query protocol defines "the" valid-action list of a state, and hence the exact action text? | Action text is model input and the minimal-pair key. Without a fixed protocol, the same state can have different action strings, and replay fingerprints (which include the valid-action list) diverge | Fixed query protocol: load → recipe actions with no interleaved queries → `capture_state` → `valid_action_templates`. It is used by the sampler, `replay()` and the restoration runner. Record it in every record | Team | Final ScienceWorld dataset | Proposed (implemented in Phase 4E). Cause [SRC]: `InputParser.chooseUniqueReferents` (`input/InputParser.scala:644`) falls back to the global `scala.util.Random` after 10 failed disambiguation attempts. That generator is seeded once per environment (`EnvironmentMaker.scala:23`) and also drives world dynamics, e.g. `Bee.scala`. Free queries could therefore perturb stochastic dynamics. This was tested in 2 greenhouse probes (bee hive open, 8 ticks, 0/1/3 queries per tick) and was **not observed** (`21` §3.2). **Phase 4F (`22` §2): measured, and the 4E null result is superseded.** Probing the state after every step k shows that valid-action enumeration changes bee transitions (which bees leave the hive) from the first tick after opening, identically in fresh and shared JVMs. In an ambiguous-referent state, it changes the valid-action text before any state difference. Look, inventory and object-tree queries changed nothing measured, and the two deterministic scenarios were unaffected by any query condition. Protocol retained as ADR-0003 D8 (consistent, not neutral) |
